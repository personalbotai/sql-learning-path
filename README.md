## ✨ Features

- ⚡ **In-Browser SQLite WASM Engine:** Execute queries natively in your browser using SQLite 3.44+ WASM with zero latency.
- 📊 **Visual Result-Set Table Renderer:** Clean, responsive tabular outputs with query execution metadata.
- 🎯 **20 In-Depth Modules:** Curated curriculum from DDL basics to recursive CTEs, window functions, and B-Tree optimization.
- 🧠 **Deep Technical Quizzes:** 20 architectural quizzes with deep relational theory and indexing explanations in Indonesian.
- 🎖️ **Graduation Certificate Generator:** High-resolution Canvas certificate generator with PNG & PDF export — gated strictly to 100% completion.
- 📱 **PWA & Offline Support:** Service Worker offline caching and Web App Manifest for an app-like mobile experience.
- ⌨️ **Command Palette UI:** Quick instant search navigation via (⌘K / Ctrl+K) across lessons.

## 📚 Curriculum Overview

1. **Fondasi RDBMS & DDL** — RDBMS vs NoSQL, `CREATE TABLE`, Constraints (`PRIMARY KEY`, `UNIQUE`), and `ALTER TABLE`.
2. **Manipulasi Data (DML)** — `INSERT`, `SELECT`, `WHERE`, `ORDER BY`, `UPDATE`, and safe `DELETE` operations.
3. **Relasi & Multi-Table Queries** — Foreign Keys, `INNER JOIN`, `LEFT JOIN`, `CROSS JOIN`, and Aggregate Functions (`GROUP BY`, `HAVING`).
4. **Query Lanjut, Subqueries & CTE** — Scalar/Correlated subqueries, Common Table Expressions (`WITH`), Recursive CTEs, and `CASE WHEN`.
5. **Window Functions & Optimasi** — `OVER`, `PARTITION BY`, `LEAD`, `LAG`, B-Tree Indexing, Query Optimization, and ACID Transactions.

## 🛠️ Local Development

Clone and run locally using any static web server:

```bash
git clone https://github.com/personalbotai/sql-learning-path.git
cd sql-learning-path
python3 -m http.server 8080
```

Open `http://localhost:8080` in your web browser.
